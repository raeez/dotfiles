# Configuration references

Use the root [source routes](../README.md#source-routes) for maintained configuration.
Read the exact file before changing it. Inspect the host separately when an installation task requires that evidence.

The former files in this directory were last changed in April 2017.
They are preserved in [`archive/2017-setup-notes/`](../archive/2017-setup-notes/README.md).
They include copied upstream tutorials and a VimOrganizer reference.
Their commands, package versions, links, and plugin assumptions are historical.
They do not establish current installation requirements or authorize host changes.
